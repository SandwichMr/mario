# aplicacionmario

Proyecto Android.

## Abrir en Android Studio

1. Abre esta carpeta desde Android Studio.
2. Deja que Android Studio detecte tu Android SDK local.
3. Si Android Studio pide configurar el SDK, selecciona la carpeta del SDK de tu laptop.

No incluyas `local.properties` en el proyecto: Android Studio lo genera en cada equipo con la ruta correcta del SDK.
